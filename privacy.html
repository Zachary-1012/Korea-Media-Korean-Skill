“韩国媒体传播韩语”是 Zachary-1012 维护的韩语学习与韩国大学申请辅助产品。

远程 MCP 服务如何处理数据

  • 工具只接收完成当前任务必要的输入，例如申请层级、TOPIK 目标、韩语词汇、学校或练习类别。默认不要求用户账号或敏感凭据。
  • 当前远程服务不建立用户个人档案数据库，也不持久存储用户写作或口语原文。
  • 网络及托管环境可能生成用于维护服务可用性的基础请求/错误日志。避免在错误日志中写入完整学习正文。

ChatGPT 内学习与批改

当用户主动点击“提交批改”“继续对话”“提交诊断”等按钮时，选中的韩语文字、练习题目和相关目标会通过 MCP Apps 的 ui/message 发送给当前 ChatGPT 对话，由 ChatGPT 进行反馈。此操作不是在本 MCP 服务器上保存作文。ChatGPT 对话数据的处理遵循用户与其 ChatGPT 服务之间适用的隐私设置和条款。

语音、发音与第三方

  • 普通韩语朗读使用浏览器/设备可用的 Speech Synthesis（TTS），并不意味着所有设备离线合成。
  • 可选的韩语语音识别由当前浏览器/设备提供；识别过程中音频可能发送给浏览器/系统供应商进行处理。因此首次主动使用前会提示用户。不同浏览器和宿主可能不支持此功能。
  • 浏览器或 ChatGPT 宿主会要求必要的麦克风权限，用户可以拒绝并改用键盘输入。
  • 官方预告片、大学网站和外部学习资源由相应第三方提供，访问后适用其隐私条款。

个人学习数据

独立 GitHub Pages 网站的学习进度、错题复习计划、用户主动提交的练习文字与场景回答、申请层级和私有字幕练习盒保存在当前浏览器 localStorage；不自动上传到 GitHub 或自有服务器。清理浏览器站点数据可能使这些记录消失；无账号跨设备同步承诺。语音转写由浏览器或设备供应商负责，本站不上传或保存录音文件。

网页端教育闭环的新数据

入学诊断、阶段听力/阅读/听写检查、错误记录、隔日复测、独立情境韩语回答、反馈来源说明、纠错重写计划均保存在当前浏览器 localStorage，不自动上传自有服务器。手机与电脑不会自动同步。用户可以导出 JSON 备份、恢复或删除本次学习记录；导出文件可能包含私人的韩语表达，务必妥善保管。

本网站允许用户自行输入老师、交流伙伴或自己的反馈，但不核实外部教师身份，也不自动声称老师确认了发音或语言等级。评分只适用于实际观察过的维度；没有听到真实发音时应选择“未验证”。浏览器 TTS 是否真的清晰播放、声音质量如何，受到设备限制；合成测试不能替代真实用户听音。

点击复制教师反馈提示词不会自动上传练习文字。只有学习者主动打开外部聊天或向老师发送文本时，对方才会依其隐私规则处理所提交的内容。

官方词典查询的网络处理

用户主动在扩展词书提交韩语词头时，浏览器将查询词传输至现有 Korean Media Study Railway 后端，服务器再向韩国国立国语院《韩国语基础词典》开放 API 发起搜索；Railway、网络基础设施和官方接口可能记录访问日志。API 认证密钥仅保存在服务器环境变量中，不暴露给浏览器。用户的词书收藏、复习进度、写作草稿和录音不会随该查询一起发送给官方接口。

新增扩展词书与韩国礼仪课程

扩展词书下载公开许可的数据文件用于本地浏览搜索，不要求用户登录，也不会将个人搜索文字发送到自有后台。用户自行收藏的词头、个人间隔复习时间、礼仪判断结果及自己输入的韩语回答存储在当前浏览器 localStorage，分别使用 kmsExtendedVocabularyV1、kmsKoreanEtiquetteV1 键值；清除浏览器站点数据会丢失这些记录。

第三方词库注明来源 Koko AI 与 CC BY 4.0；部分释义来源为英文或自动简体转换，不能保证所有词义准确。韩国国立国语院独立词典为外链，访问后遵循其独立隐私与版权政策。当前网页未向官方词典接口提交用户个人查询，也没有向外部服务器上传用户收藏列表或礼仪回答。

不进行的行为

  • 不出售个人数据。
  • 不要求银行卡、身份证、院校账号密码、Cookie 或认证令牌。
  • 不自动读取完整 ChatGPT 历史或其他未由用户主动提交的私人资料。
