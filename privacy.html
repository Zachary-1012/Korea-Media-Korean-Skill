隐私政策

最后更新：2026-10-08

“韩国媒体传播韩语”是 Zachary-1012 维护的非商业韩语学习与申请辅助项目。

我们处理什么

  • MCP 工具调用只处理完成当前学习任务所需的输入，例如申请层级、TOPIK 目标、韩语词汇、学校/专业偏好。
  • 远程 MCP 服务当前不要求账号登录，也不建立用户画像数据库。
  • 公开 GitHub Pages 的学习进度、申请层级和“私有字幕/剧本练习盒”保存在用户自己的浏览器 localStorage。

我们不做什么

  • 不会把用户贴入本地练习盒的文本自动上传到 GitHub。
  • 不会出售个人数据。
  • 不会要求或存储银行卡、身份证、学校账户密码等敏感凭据。

第三方链接

课程可能链接至 SNU、CAU、YouTube、Netflix 等官方公开页面。打开这些链接后适用对应第三方的隐私政策。

日志

服务可记录必要的运行级日志（例如请求路径、错误和健康状态）用于稳定性排查；不应记录完整学习正文作为持久用户档案。

联系

支持与问题请通过 GitHub Issues。
