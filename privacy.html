“韩国媒体传播韩语”是 Zachary-1012 维护的韩语学习与韩国大学申请辅助产品。

远程 MCP 服务如何处理数据

  • 工具只接收完成当前任务必要的输入，例如申请层级、TOPIK 目标、韩语词汇、学校或练习类别。默认不要求用户账号或敏感凭据。
  • 当前远程服务不建立用户个人档案数据库，也不持久存储用户写作或口语原文。
  • 网络及托管环境可能生成用于维护服务可用性的基础请求/错误日志。避免在错误日志中写入完整学习正文。

ChatGPT 内学习与批改

当用户主动点击“提交批改”“继续对话”“提交诊断”等按钮时，选中的韩语文字、练习题目和相关目标会通过 MCP Apps 的 ui/message 发送给当前 ChatGPT 对话，由 ChatGPT 进行反馈。此操作不是在本 MCP 服务器上保存作文。ChatGPT 对话数据的处理遵循用户与其 ChatGPT 服务之间适用的隐私设置和条款。

语音、发音与第三方

  • 普通韩语朗读使用浏览器/设备可用的 Speech Synthesis（TTS），并不意味着所有设备离线合成。
  • 可选的韩语语音识别由当前浏览器/设备提供；识别过程中音频可能发送给浏览器/系统供应商进行处理。因此首次主动使用前会提示用户。不同浏览器和宿主可能不支持此功能。
  • 浏览器或 ChatGPT 宿主会要求必要的麦克风权限，用户可以拒绝并改用键盘输入。
  • 官方预告片、大学网站和外部学习资源由相应第三方提供，访问后适用其隐私条款。

个人学习数据

独立 GitHub Pages 网站的学习进度、申请层级与用户私有字幕练习盒保存在当前浏览器 localStorage；不自动上传到 GitHub。清理浏览器站点数据可能使这些记录消失。无账号跨设备同步承诺。

不进行的行为

  • 不出售个人数据。
  • 不要求银行卡、身份证、院校账号密码、Cookie 或认证令牌。
  • 不自动读取完整 ChatGPT 历史或其他未由用户主动提交的私人资料。
